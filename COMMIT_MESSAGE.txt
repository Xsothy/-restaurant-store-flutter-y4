feat: Add drop-in location and driver tracking with GPS coordinates

Implement real-time driver location tracking for delivery orders with
latitude/longitude coordinates and comprehensive API documentation.

## Features Added

- Drop-in location support (latitude/longitude) in DeliveryInfo model
- New REST API endpoint: PUT /api/deliveries/{deliveryId}/driver-location
- DriverLocationTracker widget for live location display
- Real-time WebSocket location updates integration
- Complete OpenAPI specification in api.json
- Comprehensive documentation and quick start guides

## API Changes

### New Endpoint
- PUT /api/deliveries/{deliveryId}/driver-location
  - Request: latitude, longitude, currentLocation
  - Response: Updated DeliveryResponse with GPS coordinates
  - Auth: Bearer token required
  - WebSocket: Broadcasts to delivery topics

### New Schema
- DriverLocationUpdateRequest
  - latitude: double (required, -90 to 90)
  - longitude: double (required, -180 to 180)
  - currentLocation: string (optional)

## Data Model Updates

- DeliveryInfo model enhanced with:
  - latitude: double? (GPS coordinate)
  - longitude: double? (GPS coordinate)
  - Backward compatible (nullable fields)
